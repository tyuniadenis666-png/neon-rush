# NEON RUSH

Original one-button neon platformer prototype built with Godot 4.3.

## Controls
- Tap / click / Space / Up / W to jump.
- Tap or press R after a crash to restart.

## Build
The Android debug APK is built automatically by GitHub Actions on every push to `main` and can also be started manually from the Actions tab.

This is an original prototype and does not use Geometry Dash code, levels, music, branding, or assets.
